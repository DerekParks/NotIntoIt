# medium-rental-loss — fictional 2025 joint return

Independent runnable variation of the medium family case.

$1,000 rental loss; $65,000 wages; active participation; MAGI before the rental loss $95,339. The full loss qualifies for the special allowance and the Form 8582 exception.

AGI $94,339; QBI deduction $5,748; taxable income $57,091; income tax $6,372; total tax $6,493; payments $16,000; refund **$9,507**. Income below $100,000 uses the IRS Tax Table, not direct bracket tax.

Sources: [2025 Publication 527](https://www.irs.gov/publications/p527), [2025 Form 8995 instructions](https://www.irs.gov/instructions/i8995), [2025 Schedule C instructions](https://www.irs.gov/instructions/i1040sc), [2025 Form 1040 instructions](https://www.irs.gov/instructions/i1040gi).

Run: `python3 bench/run.py medium-rental-loss --agent pi --model provider/model --runs 1`. No model run is part of answer-key verification.
