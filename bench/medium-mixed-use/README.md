# medium-mixed-use — fictional 2025 joint return

Independent runnable variation of the medium family case.

120 fair-rental days / 150 total days used = 80%. Shared expenses $8,000 plus depreciation $8,000; rental profit $8,000. Investment rental is explicitly outside QBI.

AGI $148,339; QBI deduction $5,948; taxable income $110,891; income tax $14,224; total tax $14,345; payments $16,000; refund **$1,655**. Income below $100,000 uses the IRS Tax Table, not direct bracket tax.

Sources: [2025 Publication 527](https://www.irs.gov/publications/p527), [2025 Form 8995 instructions](https://www.irs.gov/instructions/i8995), [2025 Schedule C instructions](https://www.irs.gov/instructions/i1040sc), [2025 Form 1040 instructions](https://www.irs.gov/instructions/i1040gi).

Run: `python3 bench/run.py medium-mixed-use --agent pi --model provider/model --runs 1`. No model run is part of answer-key verification.
