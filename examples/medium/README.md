# Rivera family — medium example

Fictional 2025 joint federal return with two children, W-2 wages, Morgan's
sole-proprietor graphic design business, and a long-term residential rental.
The source packet is in `2025/intake.md` and `2025/documents/`. Text and CSV
transcriptions are intentionally used to focus on tax reasoning.

Ask an assistant using NotIntoIt to prepare the return from this workspace.
The independently calculated answer key, sources and benchmark instructions
are in [bench/medium](../../bench/medium/README.md); those files are never copied
to the benchmarked agent's workspace. Every identity and document is fictional.
